# Geki Product Brief

## Problem

Long coding sessions lose intent across context limits and coding tools. Planning frameworks produce useful specifications but their implementation loops may be weak, while specialist skills are fragmented and can conflict.

## Product

Geki installs a curated, versioned workflow into one repository. Interactive planning produces durable contracts; an explicit execution command drives selected epics through implementation, independent review, deterministic gates, GitHub Actions, and handoff checkpoints.

## Primary user

A Windows developer working mainly with .NET 8 or NestJS, PostgreSQL/Supabase, REST APIs, GitHub, Docker, and occasionally a frontend. The user may understand product requirements better than technology selection and expects architecture guidance rather than a menu of unexplained tools.

## Outcomes

- Resume work across Codex and Antigravity without chat history.
- Catch specification and architecture gaps before or during coding.
- Prefer simple framework-native architecture.
- Prove completion with test and review evidence.
- Make progress observable through a read-only dashboard.

## Non-goals for 0.1.0

- Global installation.
- macOS/Linux guarantees.
- Automatic production deployment.
- Automatic merge into `main`.
- Telemetry or hosted control plane.
- Supporting every language, ORM, or agent harness.
